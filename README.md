# 💪 健身训练记录

一个简单、纯前端的健身训练记录应用。无需安装、无需后端，所有数据保存在浏览器本地（localStorage）。

## 功能

### 1. 训练记录
- 选择训练项目并创建一次训练（默认填入当天日期）
- 记录每个动作的**组数**，每组可填写**重量**和**次数**
- 可随时添加 / 删除动作和组
- 创建训练时自动带入该项目的预设动作

### 2. 训练项目（可自定义）
- 内置示例：胸部训练、腿部训练、肩部训练、功能性训练、手臂训练
- 自由创建你自己的训练分类，并为每个项目预设动作
- 可删除不需要的项目

### 3. 训练要点
记录三类要点，并可按分类筛选：
- **训练组数建议**
- **训练要点**
- **关键技巧**

## 使用方法

直接用浏览器打开 `index.html` 即可。

或启动一个本地静态服务器：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 数据存储

所有数据保存在浏览器的 `localStorage` 中（键名 `fitness-tracker-v1`）。
清除浏览器数据会丢失记录；更换设备或浏览器数据不会同步。

## 文件结构

- `index.html` — 页面结构
- `styles.css` — 样式（深色主题，移动端友好）
- `app.js` — 应用逻辑与本地存储
