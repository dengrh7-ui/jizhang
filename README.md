# 德训录

一个简洁的训练记录应用，参考苹果生态的极简设计风格，采用苹果系统字体并针对移动端优化。
训练记录等核心功能纯前端、离线可用（数据存浏览器 localStorage）；「搭子」社群功能需运行轻量后端。

## 功能

### 1. 训练（记录 + 项目，合并为一处）
- 顶部「开始训练」：选项目、选日期、一键创建或复制上次
- 「训练项目管理」折叠卡片：按部位/目标分类创建项目（含训练目标），不占用单独页面
- 训练历史支持**按分类（项目）筛选**
- 每组记录 **重量(kg) · 次数(Reps) · RPE(6–10)**，自动算 **估算 1RM（Epley）**
- 按训练目标显示**处方建议**（Reps / %1RM / 组数 / 组间休息）
- **渐进超负荷提示**：基于上次估算 1RM、区分复合/孤立动作，应用**双递进法则**

### 2. 运动日历
- 月视图日历，有训练的日期高亮并标点
- **任意日期均可点击**查看当天训练（无记录则显示空状态）—— 已修复移动端点不动的问题

### 3. 饮食营养（个性化）
- **身体信息**：性别、年龄、身高、体重、活动水平、饮食目标
- **个性化建议**：基于 Mifflin-St Jeor 公式估算 BMR/TDEE，按目标给出每日**热量、蛋白质、碳水、脂肪**目标与 BMI
- **食物热量查询**：内置常见食物每 100g 的热量与三大宏量，可搜索
- 数据参考：Mifflin-St Jeor (1990)、ISSN 立场声明、ACSM/AND 营养声明、《运动营养学》、《中国食物成分表(第6版)》、USDA FoodData Central

### 4. 训练要点（权威知识库）
- 内置**专业知识库**（只读，带书籍背书）：Reps×强度区间、每周容量地标(MEV/MAV/MRV)、训练频率、
  渐进超负荷与双递进、RPE/RIR 量表、组间休息、Tempo、热身升重组、1RM 估算、瓦式呼吸、周期化等
- 另可添加 / 删除**自己的要点**，按分类筛选

### 5. 数据统计
- 训练概览、每周训练容量柱状图
- 动作进步追踪（估算 1RM / 最大重量 / 单动作容量）
- 1RM 估算与 %1RM 强度表
- 数据备份：导出 / 导入 JSON

> 训练知识来源：NSCA《体能训练精要》、ACSM 运动指南、Schoenfeld《肌肥大科学》、
> Helms《力量与围度金字塔》、Israetel(RP) 容量地标、Rippetoe《力量训练基础》、
> Zatsiorsky《力量训练的科学与实践》、Zourdos RPE 量表 等。

### 6. 搭子社群（组队训练）
- **创建小队**成为队长，或用 **6 位邀请码加入**他人小队
- **队长**可编辑每一天的训练计划，**队员**实时（刷新后）查看
- 显示小队成员列表与队长标识；可随时退出（队长退出自动移交）
- 此功能需运行下方后端，小队数据在成员间共享

### 进阶辅助
- **渐进超负荷提示**：基于上次估算 1RM 与动作类型给出加重建议（双递进法则）
- **复制上次训练**：一键复制同项目的上次训练（含动作、组数、RPE）作为模板

## 设计

- 苹果生态风格的极简浅色界面，分段控件式选项卡，柔和卡片阴影
- 采用 **苹果系统字体**（-apple-system / SF / PingFang SC），并针对移动端优化排版与触控
- 选项卡在窄屏可横向滑动；组数表格横向滚动，避免列被压缩
- **按需渲染**：打开时只渲染当前页，其余页签首次进入再渲染，加快移动端首屏速度

## 启动后端（「搭子」社群需要）

「搭子」社群需要一个**零依赖**本地后端（`server.js`，需 **Node 18+**），用于在成员间共享小队数据：

```bash
node server.js
# 浏览器访问 http://localhost:8000
# 手机与电脑连同一 WiFi，访问 http://你的电脑IP:8000
```

> 小队数据保存在后端目录下的 `squads.json`（已加入 .gitignore，不会被提交）。
> 用 `python3 -m http.server` 或双击打开网页时，**记录/日历/项目/要点/统计全部可用**，
> 仅「搭子」社群因无后端而不可用。需要社群功能时改用 `node server.js` 启动即可。

## 关于「Apple 健康 / Apple Watch」

按当前方案**保持网页版**，暂不接入。原因是平台限制：HealthKit 仅对原生 iOS App
（Swift/SwiftUI + HealthKit 权限）开放，网页没有任何 API 可读取健康/手表数据。
健康相关数据目前请手动记录。若未来要接入，可考虑用 Capacitor 把本网页封装为原生 App
再写 HealthKit 插件，或重写为原生 iOS App。

## 使用方法

直接用浏览器打开 `index.html` 即可。

或启动一个本地静态服务器：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 数据存储

所有数据保存在浏览器的 `localStorage` 中（键名 `fitness-tracker-v1`）。
清除浏览器数据会丢失记录；更换设备或浏览器数据不会同步。

## 文件结构

- `index.html` — 页面结构
- `styles.css` — 样式（苹果风极简浅色主题，苹果系统字体，移动端适配）
- `app.js` — 应用逻辑与本地存储
- `server.js` — 零依赖本地后端：托管网页 + 「搭子」社群接口
- `squads.json` — 社群数据文件（运行时生成，已 gitignore）
