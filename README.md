# 德训录

一个简洁的纯前端训练记录应用，参考苹果生态的极简设计风格，字体采用 Cambria。
无需安装、无需后端，所有数据保存在浏览器本地（localStorage）。

## 功能

### 1. 训练记录
- 选择训练项目并创建一次训练（默认填入当天日期）
- 记录每个动作的**组数**，每组可填写**重量**和**次数**
- 可随时添加 / 删除动作和组
- 创建训练时自动带入该项目的预设动作

### 2. 训练项目（可自定义）
- 内置示例：胸部训练、腿部训练、肩部训练、功能性训练、手臂训练
- 自由创建你自己的训练分类，并为每个项目预设动作
- 可删除不需要的项目

### 3. 训练要点
记录三类要点，并可按分类筛选：
- **训练组数建议**
- **训练要点**
- **关键技巧**

### 4. 数据统计
- **训练概览**：总训练次数、近 7 天训练、总组数、总容量
- **每周训练容量**：按周统计的容量柱状图（最近 8 周）
- **动作进步追踪**：选择动作查看历次最大重量变化
- **数据备份**：导出 / 导入 JSON 备份文件

### 5. 运动日历
- 月视图日历，有训练的日期高亮并标点
- 点击日期查看当天的训练内容与组数
- 可前后翻月

### 进阶辅助
- **渐进超负荷提示**：记录动作时自动显示上次该动作的最重一组，并建议本次的目标重量
- **复制上次训练**：一键复制同项目的上次训练（含动作与组数）作为模板

## 设计

- 苹果生态风格的极简浅色界面，分段控件式选项卡，柔和卡片阴影
- 字体优先使用 **Cambria**（未安装时回退到 Songti/Georgia 等衬线字体）

### 6. AI 教练（运动 / 营养）
由 Claude 提供建议，分「运动建议」与「营养建议」两个专门角色，可勾选「结合我的近期训练记录」获得个性化回答。
此功能需启动下方的轻量后端（API Key 仅保存在后端，前端不接触）。

## 启动 AI 教练（需要后端）

AI 教练需要一个零依赖的本地后端（`server.js`，需 **Node 18+**）来安全代理调用 Claude：

```bash
# 1) 设置你的 Anthropic API Key（密钥只存在于后端环境变量）
export ANTHROPIC_API_KEY=sk-ant-xxxxx
# 可选：指定模型，默认 claude-sonnet-4-6
# export CLAUDE_MODEL=claude-sonnet-4-6

# 2) 启动（同时托管网页与 /api/coach 接口）
node server.js

# 3) 浏览器访问
#    http://localhost:8000
```

> 说明：用 `python3 -m http.server` 或双击打开网页时，**记录/日历/统计等本地功能全部可用**，
> 仅「AI 教练」因为没有后端而不可用。需要 AI 教练时改用 `node server.js` 启动即可。
> 获取 API Key：https://console.anthropic.com/

## 关于「Apple 健康 / Apple Watch」

按当前方案**保持网页版**，暂不接入。原因是平台限制：HealthKit 仅对原生 iOS App
（Swift/SwiftUI + HealthKit 权限）开放，网页没有任何 API 可读取健康/手表数据。
健康相关数据目前请手动记录。若未来要接入，可考虑用 Capacitor 把本网页封装为原生 App
再写 HealthKit 插件，或重写为原生 iOS App。

## 使用方法

直接用浏览器打开 `index.html` 即可。

或启动一个本地静态服务器：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 数据存储

所有数据保存在浏览器的 `localStorage` 中（键名 `fitness-tracker-v1`）。
清除浏览器数据会丢失记录；更换设备或浏览器数据不会同步。

## 文件结构

- `index.html` — 页面结构
- `styles.css` — 样式（苹果风极简浅色主题，移动端友好）
- `app.js` — 应用逻辑与本地存储
- `server.js` — 零依赖本地后端：托管网页 + 安全代理调用 Claude（AI 教练）
